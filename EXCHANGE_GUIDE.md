# Return / Exchange
Sales & Returns → View original bill or choose Return / Exchange. Select original quantities, condition, reason, and Refund or Exchange. For Exchange select replacement quantities and payment method. Confirm once; a printable return/exchange receipt opens. Reopen the original bill to see returned items and linked references and print the return receipt again.

Credit uses original discounted paid value. New items use current selling price. Example: old paid value 2,000; new dress 2,800; additional payment 800. Equal price requires no extra payment. Cheaper replacement refunds the difference using the chosen method; this version does not create store credit. Payment method records the settlement; it does not initiate a card/bank transfer.

Resellable returned units increase stock; damaged units do not. Replacement quantities reduce stock atomically. Returns are within five days and cannot exceed remaining original quantities. Linked exchange receipts cannot be deleted independently. Existing cloud-synced receipts still require backend return integration.

Accounting: original bill return value reduces original sales; replacement bill records its full product value. Exchange credit is not a second cash refund. Actual refund and additional collection are stored separately in the return record. Staff payroll and online payments are outside this change.
